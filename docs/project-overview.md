# ShortFilm Agent｜创作工作台

ShortFilm Agent 是一个面向短片、电商广告、漫剧、文旅宣传和商品海报的 AIGC 创作原型。它把文本、图像和视频模型串进场景流程，把剧本、分镜、参考图等中间结果留在工作台，方便用户检查或重做局部内容。

本版本改造了首页。场景选择、当前制作步骤和需求输入按操作顺序排列；切换场景后，步骤跟随实际场景配置变化。例如，商品海报包含四个阶段，不执行视频生成或成片拼接。首页保留两种方式：逐步审阅，或自动运行当前场景。

| 场景 | 典型输入 | 流程目标 |
| --- | --- | --- |
| AI 短片 | 故事、风格、集数 | 生成分集剧本、镜头和短片 |
| 电商广告片 | 商品、卖点、受众 | 产出适合广告表达的短视频 |
| 漫剧 | 世界观、人物、画风 | 产出漫画风格的连续内容 |
| 旅游宣传片 | 目的地、地点或文化主题 | 产出文旅宣传视频 |
| 商品海报 | 商品、卖点、视觉要求 | 产出静态海报素材 |

场景由 `backend/scenarios/` 下的配置定义，前端为 Next.js，后端为 FastAPI。短片流程依次处理剧本、角色与场景设定、分镜、参考图、视频和后期；部分阶段内置模型评价与重试。后期通过 FFmpeg 拼接片段。

## 本地构建与打开

准备 Python 3.12、uv、Node.js 20.9+ 和 npm。以下命令从仓库根目录执行，分别在两个终端运行：

```bash
# 终端一：安装后端锁定依赖并启动 API
cd backend
uv sync --frozen --python 3.12
SFA_HOST=127.0.0.1 SFA_PORT=8000 uv run --frozen python api_server.py
```

```bash
# 终端二：安装锁定依赖、编译、启动生产构建
cd frontend
npm ci
npm run build
npm start -- --hostname 127.0.0.1 --port 3000
```

打开 <http://127.0.0.1:3000/>。浏览首页、切换场景和查看设置无需模型密钥；实际生成需要在设置页配置所用模型的服务商凭据，成片拼接还需要安装 FFmpeg。若改用其他端口，需在构建前设置 `BACKEND_API_URL` 和 `NEXT_PUBLIC_API_URL`，并在后端 `SFA_CORS_ORIGINS` 中配置相应前端地址。

接口默认没有账号与项目鉴权，建议用于单机学习和原型验证。直接对外部署前应补齐鉴权、会话文件访问控制及依赖安全检查。发布代码仓库不包含在线应用部署。
